How is DC doing, block by block?

A report card for the District and every one of its 8 wards, 46 Advisory Neighborhood Commissions and 345 single-member districts, built from the city's own public data. Each grade shows where an area stands and which way it is heading.

How grades work

Each area gets a letter, A to F, for how it compares with DC as a whole, and a plus or minus when it is improving or worsening faster than the city. Cutoffs are fixed, so every area can earn an A. DC itself is graded against US cities of similar size.

Built on public data

Every number comes from DC Open Data and other public sources. Each scorecard explains its measures, sources and limits, and the code that builds the numbers is published with the site.

Independent

DC Scorecard is a volunteer project. It is nonpartisan, does not endorse candidates, and is not affiliated with the DC government.
